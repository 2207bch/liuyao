# 六爻预测 · 手机版

六爻排盘断卦，理论依据《卜筮正宗·黄金策》《增删卜易》。纯前端实现，离线可用，可作为手机网页（PWA）或安卓 App（APK）分享。

## 功能
- 默认以当日起卦，日历按钮可任选日期；
- 三铜钱起卦：一键摇卦或逐爻手动点选；
- 十六类事项（求财、功名、考试、婚姻、疾病、子女、出行、官司、房子、合同、朋友等），
  婚姻分男占/女占，疾病分自占/代占；
- 完整卦盘（六神、六亲、纳甲、世应、动变、空破）；
- 每类事项均含《黄金策》对应原文、白话释义、逐条详断与应期；
- 断语区可点击放大、再点缩回。

## 文件
- `index.html` / `app.js`：网页界面与交互；
- `liuyao_core.js`：干支、起卦、装卦、旺衰、通用与求财断语；
- `liuyao_zhuan.js`：十类专断；
- `manifest.json` / `sw.js`：PWA 离线支持；
- `android/`：APK 套壳工程（WebView 离线加载）；
- `.github/workflows/build.yml`：云端自动构建 APK 并发布网页。

## 本地预览
```
node server.js
# 浏览器打开 http://localhost:8080
```

## 手机使用
- 网页：部署后用手机浏览器打开，可“添加到主屏幕”，像 App 一样使用；
- 安卓：安装云端构建出的 APK，点开即用，无需联网。
